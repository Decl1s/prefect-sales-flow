пять репозиториев серии и локальная карта. Штатная команда code --status подтвердила

автоматически не проверялись; конфигурации подготовлены для самостоятельной отладки.

Все 19 тестов повторно прошли после добавления комментариев и лабораторной.

правила, настройки запуска и оркестрация не менялись. VERSION остаётся sales-v1.
Версия учебной сборки приложения — 0.1.1; зависимости не добавлялись.
uv lock --check --offline подтвердил согласованность lock-файла.

Команды из всех восьми задач IDE фактически выполнены на Linux. Учебные входы
и выходы для проверки использовали временную папку; задача подготовки отдельно
создала пользовательский набор workspace/learn/input без готового output.
Новая запись восстановилась за 2 попытки, повтор использовал результат за 1,
inspect показал сводку, плохой статус дал ожидаемый код 1 и DataError.
Smoke завершился smoke=passed. Проверены 6 сценариев лабораторной и сохранение
пользовательской правки при повторном prepare. Добавление mug в отдельной проверке
дало ожидаемые 184000 копеек; постоянный код и допустимые товары не менялись.

Новый список публикации содержит 31 текстовый файл, включая учебные документы,
скрипт и .vscode. Проверка контактов/секретов/путей пройдена. Архив 0.1.1 собирается
из этого списка, исходная сборка 0.1.0 сохраняется отдельно. Общий workspace серии
локальный и в архив приложения не включается. Фактический SHA-256 — в SHA256SUMS
рядом с архивом и локальном журнале серии.

На 19 октября Windows-конфигурации задач и отладки были только подготовлены,
публикация и CI не выполнялись. Этот прежний статус снят проверками 21 октября.
Нажатия F5 в графическом интерфейсе остаются непроверенными. Ниже исходный отчёт 0.1.0.

## Исходная сборка 0.1.0

19.10.2026, Linux amd64, Python 3.12.14, Prefect 3.8.8, uv 0.13.1, SQLite 3.53.1.
Установленное окружение восстановлено по uv.lock из публичного PyPI.

Пройдены 14 тестов обработки: точные суммы, отмены, точные дубли, конфликт ID,
неверные поля, заголовок, пустой и повреждённый CSV, UTF-8/BOM, ограничения байт и строк,
хэш байтов, отказ перезаписи генератора, целостность манифеста, одинаковый повтор,
повреждённые результаты, очистка staging при ошибке записи, отказ входной symlink.

Настоящий smoke с временным локальным Prefect выполнен, код выхода 0:

```json
{"bad_input_blocked": true, "corrupt_output_attempts": 1, "repeat_reused": true, "retry_attempts": 2, "revenue_cents": 159000, "smoke": "passed"}
```

Первый запуск после учебного временного отказа записал результат за две попытки.
Второй использовал прежнюю папку за одну попытку; все три файла побайтово совпали.
Плохой CSV завершил flow ошибкой DataError: зависимости получили NotReady,
каталог blocked не появился. Повреждённый отчёт вызвал PublishError без повторов.
Сообщения об ожидаемых ошибках в отрицательных сценариях не считаются ошибкой smoke.

API URL и API key действительно None, аналитика выключена. Первая попытка в песочнице
не смогла создать сокет; фактическая проверка выполнена с разрешением локального сервера.
Во время разработки исправлена пустая строка URL, ломавшая EventsWorker, и устранена
зависимость проверки попыток от времени обработки событий API. Подробности в NOTES.md.

Полный набор из 19 тестов пройден: 14 проверок обработки, 2 проверки CLI/изоляции
настроек, 3 проверки публикации. Пользовательские команды demo и два run --fail-once
действительно выполнены; результат совпал с ожидаемым. Набор из 24 исходных файлов
проверен на типовые секреты, контакты и приватные пути. ZIP распакован в отдельную
временную папку: все байты совпали с PUBLIC_FILES.txt, повторно прошли 19 тестов и smoke.

Публикация не выполнена. Подключение GitHub подтвердило отсутствие
Decl1s/prefect-sales-flow (404). Встроенный браузер отказал в доступе к GitHub,
поскольку не смог проверить политику администратора. Ограничение не обходилось;
доступные инструменты подключения не создают репозитории и релизы. Готовы локальные
исходники, архив 0.1.0 и SHA256SUMS для публикации после восстановления доступа.
CI подготовлен для Ubuntu и Windows, но не запускался. Windows локально не запускался.

Не проверялись параллельные писатели, питание/kill в момент переименования,
производительность на предельном входе и рабочие данные. Windows локально не запускался.
Нет заявления о безопасности обработки произвольных пользовательских документов.
